你的知识，随时继续。

在这台电脑管理知识库，或连接已有的 Second Mind 服务器。

本机

本机使用

文件保存在你选择的文件夹中，任务在此电脑执行。模型与联网服务可进入工作区后配置。

    先选择一个在 Obsidian 中打开过的 Vault 根文件夹。

    首次启动会建立关键词索引，不会自动调用付费模型。添加文件夹时，需等待本机任务完成。

    远程

    连接服务器

    使用服务器上的知识库、账号和模型配置。各服务器独立登录，数据保留在服务器。

      公网连接使用 HTTPS。局域网 HTTP 中的录音受浏览器限制。

      语音与视频转写

      进入本机工作区后可下载语音模型。

      使用 small 模型在本机 CPU 上转写。首次使用需要下载模型；后续复用本机缓存。

      本机运行状态

      后台尚未启动。

      切换到远程时，本机任务继续运行。关闭窗口后可从系统托盘恢复；退出软件会停止本机任务。

      本机与服务器之间不会自动同步数据。
