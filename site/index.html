自己的密钥，自己的选择

BYOK · 保存的 API Key 仅留在服务端，不回传浏览器，也不交给 SDK 子进程。

DeepSeek 官方

api.deepseek.com/anthropic/v1/messages

原生 Messages 接口。每个任务沿用启动时选择的模型和凭据。

阿里云百炼

dashscope.aliyuncs.com/apps/anthropic/v1/messages

Qwen 3.8 Max 可结合图片和 PDF 回答，原生思考等级在配置页选择。

Kimi

api.moonshot.cn/anthropic/v1/messages

使用 Kimi 的 Messages 接口，在配置页核验凭据与模型 ID。

自定义 Anthropic 端点

models.example.com/v1/messages

示意地址。填写你的兼容端点、认证方式与模型 ID，再运行连接检查。

Tavily 联网

api.tavily.com/search

单独配置搜索密钥。开启联网补充时发送查询，个人学习回顾只读所选知识库。

本地 Whisper + FFmpeg

FFmpeg → faster-whisper

提取关键帧并在本机转写。首次使用需准备语音模型，提取内容可随任务交给所选模型。

外部模型会收到问题、附件和选中的笔记片段；远程 Embedding 服务会收到参与索引的文本。不开启模型也可使用本机关键词检索。 查看数据流 ↗

一条有边界的执行链

适合怎样的书房？

设计目标

  • 单管理员，在自己掌握的设备上自托管。
  • 原文证据优先，写入前审核草稿。
  • BYOK 接入模型，多知识库独立运行。

明确非目标

  • 多租户账号和细粒度团队权限。
  • 跨库联合检索或合并多个库的上下文。
  • 托管 SaaS 或代管你的 API 账单。
