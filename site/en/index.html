Privacy architecture

Where does a question go?

  1. Local Vault

    Original notes stay on your computer or server.

  2. Scoped retrieval

    The server reads the active Vault. Search tools cannot run a shell or edit files.

  3. External model

    The model receives the question, context, relevant passages and submitted attachments.

  4. Reviewed write

    The app stages a draft. It writes to your Vault after you review and confirm.

Keyword search runs locally. Building a remote semantic index sends eligible note chunks to your embedding provider. See the full data flow
