“检查并保存”会执行真实连通测试

单卡“检查连接”只调用目标 Provider，不调用 WebSearch、不保存生效；检查结果在服务器临时保留，页面任意修改 Provider、模型或联网配置后自动失效。最终保存只实测尚未检查的模型，再检查当前搜索供应商及抽取兜底，可能产生费用；保存 receipt 不会再次调用模型。

凭据安全

  • 所有 API Key 独立保存在服务器，不回显、不写入 URL 或浏览器存储。
  • 切换供应商不会在不同服务间复用 Key；改变 API 地址时必须填写目标地址对应的新 Key。
  • 已配置的 Key 留空即可保留，输入新值即替换；删除 Provider 会同时删除它的服务端凭据。
  • 请求发出后 Key 会从页面清空，页面内存只保留不含密钥的暂存编号，精确候选仅在服务器内存保留最多 10 分钟。
