Recorded answer

Draft generation A low-cost draft model (distribution q) proposes a sequence of tokens autoregressively. This gives the target model a hypothetical prefix to verify. The draft model introduces parallelism. Its quality affects the acceptance rate but leaves the final distribution intact. [1]

Parallel verification With the candidate tokens in place, the target model (distribution p) can evaluate a whole block in one forward pass. A causal mask lets it compute the target distribution at each candidate position in parallel, using one read of the weights across several positions. [2]

Limits to the speedup Speculative decoding tackles the memory bottleneck during decoding. The sampled answer says that fewer sequential steps and weight reads lower time to first token. It also says total FLOPs do not fall, prefill is unaffected, and gains are greatest at low concurrency with long, memory-bound outputs. At large batch sizes or high concurrency, the gain can shrink or reverse. [3]

Source check The answer mentions time to first token. Line 241 identifies time per output token (TPOT/ITL) as the gain and says prefill sees little speedup. [3]

    Bring your own keys

    BYOK · Stored API keys stay on your server. The browser can only check whether a key is configured. Only the server attaches it to requests to your provider.

    DeepSeek

    api.deepseek.com/anthropic/v1/messages

    Native Messages transport. A task uses the model and credential selected at launch.

    Alibaba Cloud Bailian

    dashscope.aliyuncs.com/apps/anthropic/v1/messages

    Qwen 3.8 Max accepts images and PDFs. Choose a supported reasoning level in Settings.

    Kimi

    api.moonshot.cn/anthropic/v1/messages

    Connect to Kimi’s Messages endpoint and verify the credential and model ID in Settings.

    Custom Anthropic endpoint

    models.example.com/v1/messages

    Example address. Supply your compatible endpoint, authentication method and model ID, then test the connection.

    Tavily search

    api.tavily.com/search

    Search has its own credential. Enabled web searches send a query to Tavily. Personal learning reviews stay within the selected Vault.

    Local Whisper + FFmpeg

    FFmpeg → faster-whisper

    Extract frames and transcribe locally. Prepare a speech model on first use. Selected content can be sent to the model handling the task.

    External models receive the question, attachments and selected excerpts. Remote embedding services receive text for indexing. Local keyword search works without a model key. Data flow ↗

    What is this workspace built for?

    Designed for

    • A single-admin, self-hosted workspace on your own hardware.
    • Source-first answers and a draft you review before writing.
    • BYOK model access and isolated Vaults.

    Outside the scope

    • Multi-tenant accounts and fine-grained team permissions.
    • Cross-base federated search or shared context across Vaults.
    • Hosted SaaS or managed provider billing.
