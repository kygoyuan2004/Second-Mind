# 项目介绍与证据

Second Mind 是围绕 Obsidian Vault 的自托管知识工作台。项目以原版 Claude Agent SDK 知识库为基准，保留检索、工具循环、多轮会话和确认写入，同时接入多知识库及服务端凭据配置。

可用于项目介绍的技术事实：

- 固定 SDK 版本和原版提示词、任务预算，避免替换执行方式后仍宣称行为相同。
- 通过每任务回环转发器将真实模型 Key 留在服务器，隔离 SDK 状态与宿主机配置。
- 旧状态只读保留，新状态增量迁移；旧草稿确认仍受原写入边界约束。
- 使用原版关键词、语义与混合检索，并保留各库独立的 Embedding 索引激活。
- 将离线测试、完整应用浏览器测试、真实供应商调用和部署验证分开记录。

性能、准确率、平台与发布状态只能引用[实际验收记录](claude-sdk-migration.md)，不要沿用旧执行器的指标。生成式模型可能遗漏引用格式或增加草稿说明；人工预览是产品流程的一部分。
